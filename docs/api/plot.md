# Plotting

Visualization tools for ABC results.

## Prior Visualization

### draw_prior

Draw samples from prior and visualize distributions.

::: approxbayescomp.plot.draw_prior
    options:
      show_root_heading: true
      show_source: false
      heading_level: 3

## Posterior Visualization

### plot_posteriors

Plot posterior distributions from ABC populations.

::: approxbayescomp.plot.plot_posteriors
    options:
      show_root_heading: true
      show_source: false
      heading_level: 3

### weighted_distplot

Plot weighted distribution (histogram/KDE) for ABC particles.

::: approxbayescomp.plot.weighted_distplot
    options:
      show_root_heading: true
      show_source: false
      heading_level: 3
